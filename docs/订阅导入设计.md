# 节点组订阅导入设计

## 数据模型

`NodeGroup` 是订阅的唯一父级：

- `SubscriptionUrl` 为空时，它是可手动添加节点的空组，默认 `sing-box`、不自动更新。
- `SubscriptionUrl` 为 HTTPS 时，它是订阅组，初始界面选择“自动判断”、默认每 6 小时更新。
- URL 存于 `data/state/node-groups.json`，因为定时更新必须使用它；界面仅显示主机名，日志隐藏 URL 参数、片段和用户信息。

`ProxyNode` 始终包含 `GroupId`。存储层在保存或整组替换前验证父级存在，因此不会产生孤儿节点。

## 下载与解析

1. 仅接受无用户信息的 HTTPS URL。
2. 限制重定向次数、超时、响应体大小和节点数量。
3. 支持 Base64 包装或逐行明文的 `ss://`、`vmess://`、`vless://`、`trojan://`。
4. 每个可识别 URL 解析为 sing-box 出站 JSON；不支持项计入跳过数，不记录原始链接。
5. 下载和解析成功后，使用 `ReplaceForGroupAsync` 在一次原子状态写入中替换该组节点。

## 刷新语义

- 同一分享链接尽量保留节点 ID、创建时间和启用状态。
- 成功时更新节点组的 `CoreId`、`LastUpdatedAt`；失败时保留旧节点并记录不含 URL 的错误。
- 自动刷新仅检查用户配置了更新时间的节点组；手动“立即更新订阅”使用相同流程。

## 当前限制

当前 URI 导入器生成 sing-box 出站，因此识别出的核心为 `sing-box`。Mihomo 可在设置页下载并运行用户导入的原生 YAML/JSON 配置；Clash YAML 订阅和更广泛的 v2rayN 格式将在后续解析器中补充。
