# WFly v0.1.0 Windows 发行说明

`WFly.exe` 是 Windows x64 的轻量代理内核管理器。它不内置节点、订阅或账号；请在程序中选择自己的本地 JSON 配置。

## 运行

1. 安装 .NET 8 Desktop Runtime x64。
2. 运行同目录中的 `WFly.exe`。
3. 选择 sing-box 或 Xray-core，检查并下载官方内核。
4. 核对版本、下载地址与 SHA-256 后确认下载，再选择本地 JSON 配置并启动。

程序数据和已验证内核位于 `%LOCALAPPDATA%\WFly`，不会写入程序所在目录。

## 重要边界

- 当前仅支持 Windows x64。
- 不修改系统代理、TUN、DNS、防火墙或路由表。
- 缺少官方 SHA-256 元数据、校验失败或 ZIP 不安全时，WFly 会拒绝安装。
- 日志仅保留在内存中；程序仅保存配置文件路径，不保存配置内容。

WFly 不随程序分发任何内核。使用代理软件时，请遵守所在地法律、网络规则以及 sing-box、Xray-core 的上游许可证。

从源码构建与完整说明请参阅仓库根目录的 `README.md`。
