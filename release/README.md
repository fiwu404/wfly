# WFly V0.1.0 发布说明

## 本版变化

- 托盘控制小窗改为更窄的圆角布局，代理模式文字简化为“系统 / 关闭 / TUN”；点击桌面、其他窗口或小窗外区域都会自动收起。
- 应用图标改为圆角蓝色渐变与双色纸飞机，并作为多尺寸图标写入 EXE、窗口和托盘。
- 节点列表精简为节点、协议、服务器、端口和四类测速结果，不再显示内核与启用列。
- 可用 Ctrl/Shift 多选节点，并通过工具栏或右键菜单批量测试 Ping、TCPing、真连接及 UDP。
- 规则模式即使没有用户规则，也会生成指向当前节点的明确兜底路由。

WFly 是 Windows x64 轻量代理客户端。它按需下载并校验 sing-box、Xray-core、Mihomo 官方内核；节点、订阅、规则和运行状态均保存在可执行文件所在程序目录下的 `./data/`，支持将整个程序目录拷贝到其他位置后直接携带数据运行。

本版重做了“添加/编辑节点”。窗口按照协议显示服务器、端口、认证及协议专用字段，并把传输、TLS/Reality、分享链接导入和高级 JSON 分页组织。VMess、VLESS、Shadowsocks、Trojan、Hysteria2、TUIC、WireGuard、SOCKS、HTTP、AnyTLS、Naive 均可直接填写表单；SS、VMess、VLESS、Trojan 分享链接可解析并回填。字段结构参考 [v2rayN](https://github.com/2dust/v2rayN) 的公开节点模型。

## 首次使用

1. 安装 .NET 8 Desktop Runtime x64 并运行 `WFly.exe`。
2. 在“节点组”创建手动组，或填写 HTTPS 订阅链接。带链接的组默认每 6 小时更新；留空则不自动更新。
3. 在“节点”添加节点，或从订阅组更新导入。
4. 在“设置”下载所需内核。Mihomo/Xray-core 需要从设置导入其原生配置文件；sing-box 可直接由已选节点生成配置。
5. 回到首页，将三档开关拨到系统代理或 TUN 模式即可启动节点；回到中间关闭代理即停止内核。

设置页将“本地运行设置”和“内核下载与更新”并排显示；内核下载进度以 5px 细条嵌入每行“已安装版本”单元格，未安装时显示“下载”。托盘使用与主界面一致的自绘弹出菜单，提供节点、代理开关和代理规则；支持日夜主题与 370×560 小型化窗口。

“本地运行设置”新增 GeoFiles 智能分流。点击“更新 GeoFiles”后，程序将 `GeoSite 中国大陆域名` 与 `GeoIP 中国大陆地址` 两个官方 sing-box `.srs` 规则集写入同目录 `data/geofiles`。规则模式启动 sing-box 时，用户规则优先执行，随后命中这两个数据集的流量直连；其余流量保持原有默认路由。更新运行中的数据后重启 sing-box 即可生效。

内核下载状态进一步收敛：未安装且空闲时，版本列显示可点击的“下载”；进入检查或下载后入口立即隐藏；只有真实下载中显示 5px 进度细条，安装完成后只显示版本号。

## 重要说明

- 系统代理仅适用于 WFly 生成的 sing-box 配置，且只在用户明确选择该模式后设置到本机 `127.0.0.1`；退出时只会恢复仍由 WFly 持有的设置。导入的 Mihomo/Xray 原生配置不会被强行指向未知端口。
- TUN 需要管理员身份；切换到 TUN 时 WFly 会请求 Windows UAC 授权，并在授权后自动继续启动。当前一键 TUN 仅生成 sing-box 配置。
- 日志默认只在内存中；使用“导出日志”后才会写入 `data/exports/`。
- IP 检测和网站延迟测试均由用户点击触发。IP 类型会查询公开 HTTPS 归属服务；无法取得结果时明确显示可重试失败状态。
- 测试页的“解锁情况”只反映 HTTP 网页是否可访问或受限；它不能代替需要登录、播放或地区内容验证的真实解锁检测。
- “通过本地代理”只会在 WFly 当前运行的 sing-box 混合代理端口可确认时启用；代理未启动时测试页明确改为直连，避免把本地端口未监听误判为网站不可访问。
- 订阅 URL 和节点凭据可能敏感，请保护 `data/` 目录；界面仅显示订阅主机名，日志会隐藏 URL 参数。

## 安全边界

WFly 仅从内置的官方 GitHub 仓库下载匹配 Windows x64 规则且附带 SHA-256 摘要的 Release 资产。下载后会校验摘要并安全解压，拒绝不安全 ZIP 内容。SHA-256 保证下载完整性，不能取代对上游发布者和订阅提供者的信任判断。
